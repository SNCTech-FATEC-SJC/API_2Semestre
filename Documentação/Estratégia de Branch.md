#  Estratégia de Branch — SNCTECH

> **Resumo:** o projeto tem uma branch principal, a `main`, que guarda sempre a versão estável e pronta para entrega. Cada dupla desenvolve uma parte do sistema em sua própria branch, separada das demais, e só integra o trabalho à `main` quando a funcionalidade está completa e testada.

---

### 🚀 Branch principal

| Branch | Descrição |
|---|---|
| **`main`** | Código estável e pronto para entrega. |
