# 🎯 Definition of Ready (DoR)

**Equipe:** SNCTECH

\---

## DoR Geral



Uma User Story está pronta para desenvolvimento quando existirem informações suficientes para a equipe iniciar o trabalho sem precisar tomar decisões fundamentais sobre ela.



* Está claro que a funcionalidade deve permitir ao usuário.
* Está claro o que faz e o que não faz parte da US.
* Não existem decisões pendentes.
* Todas as dependências são conhecidas.
* Está seguindo o fluxo principal do projeto.
* As informações necessárias e relacionamentos estão identificados.
* Está claro quem pode utilizar a funcionalidade.
* Os critérios de aceitação estão claros.
* A interface está funcional.
* Não existe bloqueio técnico funcional ou externo.
* O esforço para a US está estimado.
