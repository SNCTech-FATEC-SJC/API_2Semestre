# API_2Semestre
Repositório do projeto de API do 2º Semestre de Banco de Dados da Fatec SJC - Prof Jessen Vidal, Equipe SNC Tech!

## Telas

- `pom.xml`: dependências e configuração Maven do projeto JavaFX.
- `src/main/java/br/snctech`: aplicação principal, controllers e navegação entre telas.
- `src/main/resources/br/snctech`: arquivos FXML e estilos visuais das telas.
- `Professor(1).png`: referência visual do projeto.
- `.gitignore`: evita o envio de artefatos compilados e arquivos locais.
